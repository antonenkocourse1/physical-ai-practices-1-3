# P3: ручное управление, 8 октября 2026

Дополнительный клавиатурный Cartesian/IK-helper к неизменённой среде курса. Штатный teleop передавал команды XYZ непосредственно в действия суставов; helper переводит выбранные оператором приращения XYZ через Якобиан, удерживает ориентацию кисти и не даёт сохранить ложный успех. Экспертная политика не используется. Физика, камера наблюдений, критерий успеха и лимит 600 шагов сохранены. Между командами физика приостановлена.

## Результат и границы

- `manual_20261008T120118_249353`: неудача, 102 шага, 23 события клавиатуры, 5,10 с симуляции.
- `manual_20261008T120605_109685`: успех на шаге 135, seed 42, 38 событий, 6,75 с симуляции и 167,83 с реального времени. Высота куба 0,525815 м, расстояние до цели 0,045533 м; захват закрыт.
- GUI управлял ассистент, а не ученик. После первой неудачи для выбора перемещений использованы также координаты сохранённой записи. Опыт не является исключительно визуальным управлением или оценкой обобщения.
- Первая попытка сделана до небольшого изменения удобства камеры; сохранён финальный helper, отдельной ранней копии нет. Алгоритм управления не менялся.
- До helper в исходном teleop были две попытки: первая отменена, у второй нет сохранённой траектории или подтверждённого успеха. Их нельзя считать успешными.
- Это один успешный эпизод, не обучение политики и не подтверждение Docker/VNC или всех требований курса. Успех не проверяет отпускание куба.

## Содержимое

`episodes/*.npz` и JSON сохранены побайтно: обе попытки, изображения, действия, состояния, время, флаги среды и события клавиатуры. NPZ читается через `numpy.load(..., allow_pickle=False)`.

`independent_audit.json` содержит результаты исходной независимой проверки: целевые XYZ восстановлены точно; действия по кэшированной кинематике совпали с допуском 1e-5 (максимум около 3,75e-6). Побитовый повтор действий и полный повтор физики не подтверждены. Встроенные raw-source хеши могут относиться к файлам полного исходного архива, которые в компактную публикацию не включены.

`manual_success_actual_frames.png` — монтаж 12 реальных состояний камеры на захвате, не скриншоты рабочего окна; `frame_selection.json` описывает выбор. Видео и полные журналы исключены как необязательные для компактной поставки.

## Запуск в подготовленной среде

Нужны NumPy, MuJoCo, зависимости `P3/code`, mesh-ассеты курса в `P3/code/assets/` и графический дисплей. Исторический ручной runtime: Python 3.12.14, MuJoCo 3.5.0, Torch 2.6.0+cpu. Здесь изменён только импорт helper: соседний каталог `working` заменён на `code`, что записано в `SOURCE_PROVENANCE.json`.

Из корня репозитория:

```sh
MUJOCO_GL=glfw python P3/manual/manual_cartesian.py --seed 42 --save-dir new_manual_episodes
MUJOCO_GL=egl python P3/manual/test_manual_cartesian.py
```

Графический запуск опубликованной раскладки заново не выполнялся. Четыре headless-теста этой копии helper повторно проверены с сохранёнными ассетами курса в отдельной временной раскладке. Ассеты не входят в репозиторий; без них этот тест не запустится. Тесты реализации не считаются демонстрационными эпизодами.

Клавиши: W/S — ±X, A/D — ±Y, E/Q — ±Z; C — шаг 1/3 см; Space — захват; точка — 10 шагов удержания; T/B — ракурс; F — честно сохранить неудачу; R — отменить; Enter — сохранить только реальный успех; Escape — сохранить незавершённую попытку и выйти. Оси мировые, не экранные.
